# optiluxx.in

Website for Optiluxx Electricals LLP. Static HTML, hosted on Netlify.

- `index.html`, `indoor.html`, `outdoor.html`, `product.html`, `about.html`, `projects.html`, `clientele.html`, `contact.html`
- `assets/data.js` holds every product (generated from the AURA indoor and NOCTURNE outdoor catalogues)
- `assets/img/p/` catalogue pages, `assets/img/h/` large images, `assets/img/projects/` project photos
- `_build/` the scripts that generate the pages (`python3 _build/build.py`)
